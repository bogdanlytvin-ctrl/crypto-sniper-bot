# /fix-bug — Автоматичний пайплайн фіксу бага

Завдання користувача: **$ARGUMENTS**

Проведи повний цикл. Звітуй на кожному етапі коротко, але не зупиняйся для підтвердження між етапами (працюй автономно, зупинись лише якщо CRITICAL security або потрібне видалення/деструктивна дія).

## Етапи

### 1. ЛОКАЛІЗАЦІЯ
Запусти субагента **bug-hunter** через Task tool, щоб знайти і локалізувати баг. Передай йому опис і область пошуку.

### 2. ФІКС
На основі звіту bug-hunter запусти **code-agent**, щоб виправити баг. Дай йому точні `file.py:N` та діагноз. Прослідкуй щоб фікс був мінімальний — без зайвого рефакторингу.

### 3. ПЕРЕВІРКА (паралельно)
Запусти одночасно:
- **reviewer** — чи фікс якісний, чи не зламав щось поруч
- **security** — чи фікс не вніс вразливість (якщо торкається input/auth/SQL/payment)

### 4. ТЕСТ
Якщо є тести — запусти релевантні через Bash. Якщо нема — поясни як перевірити вручну.

### 5. ЗВІТ (формат CLAUDE.md)
```
## Звіт: fix-bug | [дата]
### Знайдено: [що було, file:N]
### Причина: [root cause]
### Фікс: [що змінено, file:N]
### Перевірка: Reviewer ✅/⚠️ | Security ✅/⚠️ | Тести ✅/⚠️
### +10%: [одна пропозиція]
```

Після завершення онови `.claude/agent-memory/BUG_REGISTRY.md` (новий баг + статус FIXED).
