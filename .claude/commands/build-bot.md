# /build-bot — Пайплайн побудови Telegram-бота

Завдання: **$ARGUMENTS**

Стек: Python 3.12 + aiogram 3.x + SQLAlchemy 2 async + Pydantic v2.

## Етапи

### 1. ВИЗНАЧЕННЯ ФУНКЦІОНАЛУ (разом з користувачем)
ЗУПИНИСЬ і узгодь з користувачем перш ніж кодити:
- Які команди/сценарії? (/start, меню, FSM-флоу)
- Чи є підписка/тири? Платежі?
- Чи є адмінка? БД? Які сутності?
- Інтеграції (API, вебхуки)?
Покажи короткий список функціоналу → дочекайся "ок" або правок.

### 2. ПЛАН (формат CLAUDE.md)
Покажи: файли що створяться, структуру, FSM-стани, схему БД, ризики. Дочекайся підтвердження.

### 3. КОД
Запусти **code-agent**:
- `bot.py` — точка входу, Router, реєстрація handlers
- handlers, keyboards, FSM
- `database.py` — моделі SQLAlchemy 2 async
- Pydantic-валідація вводу
- `config.py` — env vars (токен у .env!)
- ThrottlingMiddleware (rate limit)

### 4. SECURITY + REVIEW (паралельно)
- **security** — webhook secret, payment validation, rate limit, secrets у .env, tier-перевірки в handlers
- **reviewer** — якість, async коректність, no N+1

### 5. ТЕСТ
- Перевір імпорти (`python -c "import bot"`)
- Напиши/прогони базові тести логіки якщо доречно
- Поясни як запустити локально (polling) для ручної перевірки

### 6. ЗВІТ
```
## Звіт: build-bot | [дата]
### Функціонал: [узгоджений список]
### Файли: [створені, з рядками]

### Як запустити: [команда]
### +10%: [пропозиція]
```
