Telegram Bot — пряме підключення
Не налаштовано
Найнадійніший спосіб. Заявки надходять у ваш Telegram-бот одразу після відправки форми — без Make.com і без посередників.
Отримати: напишіть @BotFather → /newbot → скопіюйте токен
Ваш особистий ID або ID групи. Додайте бота в групу і він надішле ID.
ЯК ПІДКЛЮЧИТИ (4 кроки):

Відкрийте Telegram → знайдіть @BotFather → надішліть /newbot

Введіть назву: SEVEN+ Заявки, username: sevenplus_bot → скопіюйте Token вище

Натисніть «Знайти Chat ID» → напишіть своєму боту будь-що → поверніться і натисніть знову

Вставте Chat ID → Зберегти зміни → «Надіслати тест» → перевірте бота

Formspree — пряма відправка на Email
Не налаштовано
Заявки приходять на ваш email без посередників. Безкоштовно 50 заявок/місяць. Можна використовувати разом з Telegram Bot — заявка надійде в обидва канали.
ЯК ПІДКЛЮЧИТИ (3 кроки):

Зайдіть на formspree.io → Sign Up → New Form

Вкажіть ваш Email → скопіюйте посилання виду https://formspree.io/f/xxxxxxxx

Вставте Email та Endpoint вище → Зберегти → Надіслати тест → перевірте пошту
